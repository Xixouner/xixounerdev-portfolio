# Guide — accepter et archiver les DPA dans les comptes

> Les PDF du dossier `dpa/` sont les **versions publiques** des accords. L'acceptation contractuelle
> se fait dans chaque compte fournisseur. Cocher la case au fur et à mesure et archiver la preuve
> (capture/PDF) dans `dpa/`.

## Resend

1. Se connecter à https://resend.com → **Settings** → section légale/compliance.
2. Télécharger ou accepter le **Data Processing Addendum** (DPA).
3. Archiver la version acceptée et noter la date dans le tableau ci-dessous.

## Hetzner

1. Se connecter à **Robot** (https://robot.hetzner.com) ou à la console Cloud.
2. Section **Données personnelles / Data Protection / AVV** → valider l'accord de sous-traitance.
3. Télécharger la version validée (DE/EN) et la conserver.

## Backblaze

1. Se connecter au compte B2.
2. Vérifier la version du DPA applicable au compte (le PDF public archivé date du 27/09/2021 ;
   le compte peut proposer une version plus récente).
3. Enregistrer la version applicable et la date.

## GitHub

1. Vérifier l'acceptation des **Customer Terms** (compte GitHub).
2. Si un DPA signé est nécessaire (client grand compte), le demander via le support GitHub.
3. Conserver la référence du document.

## Google Cloud (Places API)

1. Accepter le **Cloud Data Processing Addendum** dans la console Google Cloud.
2. Conserver la référence et la date.

## Namecheap

1. Demander le DPA au support (registrar) si un client l'exige.
2. Conserver la réponse.
